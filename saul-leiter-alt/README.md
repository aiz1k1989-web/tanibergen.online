# TANIBERGEN - Alternate Portfolio

This is an independent visual direction inspired by the restrained, image-led editorial presentation of the Saul Leiter Foundation website. It uses only Tanibergen's photographs and original text.

## Preview

https://tanibergen.online/saul-leiter-alt/

## Pages

- `index.html` - Work and selected photographs
- `about.html` - Short personal introduction

There are no News, Exhibitions, Color / Black & White categories, or invented captions.

## About text

"I'm a photographer based in Bangkok, Thailand. I occasionally make videos, too. After leaving office life, I'm figuring out what comes next. Open to collaborations."

## Site notes

Open the author notes interface with:

https://tanibergen.online/saul-leiter-alt/?notes=1

Enter a slash command on the first line, followed by the requested change. Example:

```
/upd#1
On the About page, fix the wording in the small window.
```

Notes are saved in this browser using local storage. Use **Open all in GitHub** to open a prefilled GitHub Issue. GitHub does not accept writes from a public static page without an exposed credential, so the final **Create issue** click is made on GitHub after signing in. The report then remains in the repository's Issues tab and can be reviewed and fixed later.

All photographs are loaded from the numbered folders in the repository root. The image files are not duplicated in this directory.
