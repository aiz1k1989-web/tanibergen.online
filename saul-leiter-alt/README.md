# TANIBERGEN - Saul Leiter-inspired alternative

This folder contains an independent editorial portfolio version, inspired by the restrained, image-led structure of the Saul Leiter Foundation. It uses Tanibergen's own photographs and text.

Preview: https://tanibergen.online/saul-leiter-alt/

## Pages
- `index.html` - Work
- `about.html` - About

No News, Exhibitions, Color / Black & White categories, paintings, or invented captions.

## About text
"I'm a photographer. I also make videos from time to time. After leaving office life, I'm still figuring out what comes next. Based in Bangkok, Thailand. Open to collaborations."

## Author notes
Open the site with `?notes=1` to show the **+ Note** control.
Use a command such as:

```
/upd#1
On the About page, correct the wording in the second paragraph.
```

Notes are saved in this browser and can be collected across the Work and About pages. **Open all in GitHub** prepares one issue containing the notes. The final **Submit new issue** click is made on GitHub. The static website does not contain a GitHub credential.

The photographs load from the numbered root folders. Image files are not duplicated in this folder.
