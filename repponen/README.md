# Repponen-inspired archive

A separate editorial direction for tanibergen.online. It borrows principles from Anton Repponen's personal work: confident typography, visual rhythm, asymmetric composition, and a website that feels like a designed object. It does not copy his assets, text, or exact layout.

## Implementation
- Uses the current root archive manifest from ../index-main-works.js.
- Deduplicates paths and preserves the opening self-portrait as item one.
- Uses high-resolution cut-previews for the gallery; untouched originals load only in the viewer.
- Keeps natural image proportions and reserves image dimensions from ../previews/metadata.json.
- Static HTML, CSS and JavaScript. No external libraries or tracking.
- Mobile layout, keyboard navigation, touch swipe, reduced-motion support, and focus cleanup.
